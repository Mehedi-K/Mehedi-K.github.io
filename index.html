Background

I started as a QA Automation Engineer, building test suites and pipelines that catch regressions before they reach production. That work took me deeper into infrastructure — the systems tests run on, not just the tests themselves — and into full-stack development, building the backend services and frontend interfaces those systems test. I now operate as a Senior Solutions Architect while continuing hands-on full-stack and automation work.

Beyond browser and API test automation, I build RPA (robotic process automation) with RPA Framework on top of Robot Framework to automate arbitrary software — desktop applications, legacy systems, anything with an interface — not just the web.

My experience spans domains with very different failure tolerances: media, publishing, financial services / investment, and public safety. Each taught me a different definition of "broken."
